## How the guides are tested

Every integration guide opens with a "Verified" note. It gives the date the instructions were last run and the exact package versions they were run with, and the install commands on the page use the same versions. If you use a different version, the steps may differ.

Each guide also lists what Spanlight records from that library and what it does not, so you know what the dashboard can show before you rely on it.
